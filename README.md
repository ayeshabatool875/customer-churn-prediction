# Customer Churn Prediction

A machine learning model that predicts which customers 
are likely to stop using a service — so businesses can 
take action before losing them.

## Features
- Churn probability score per customer
- Key risk factors identification  
- Visual churn analysis dashboard
- Actionable retention recommendations

## Tech Stack
- Python (Pandas, Scikit-learn, XGBoost)
- Matplotlib / Seaborn for visualization
- Logistic Regression + Random Forest

## Business Impact
- Identify 85%+ of churning customers in advance
- Reduce customer loss by 20-30%
- Prioritize retention budget smartly

## Use Cases
Telecom, banks, SaaS, e-commerce, hospitals
